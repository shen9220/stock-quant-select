③ 要准备什么

证件与票务

  • 身份证原件
  • 各景点预约截图（离线）
  • 演唱会票 + 入场须知
  • 返程电子客票
  • 酒店地址（方便打车）

每日随身

  • 相机 + 电池 + SD 卡
  • 充电宝 ≤20000mAh
  • 小风扇、伞、纸巾
  • 水杯、防晒、润唇膏
  • 塑料袋、补妆、口罩
  • 舒适走路鞋

相机建议

  • 广角：中轴、万春亭、十七孔桥
  • 中长焦：雕梁、人像
  • 雍和宫殿内禁止拍摄
  • 降旗时勿举过高挡视线

遗忘补充

  • 天安门降旗预约
  • 返程最晚到站时间
  • 酒店早餐 / 寄存行李
  • 创可贴、肠胃药、防暑药
  • 演唱会耳机 / 薄外套
  • 寄快递纸箱胶带
DAY 1 · 青绿

④ 8/27 周四 · 国博 + 降旗

落地 → 文化重器 → 仪式感
  • 09:45–11:20
    落地 → 酒店：T2 对面 P2 滴滴候车区。约 50 分钟 / ¥50，约 11:00 到酒店。
  • 11:20–17:20
    国家博物馆：交通约 55 分钟，目标 13:00 入场，游玩约 4.5h。
    捷径：进馆右手 → 屹立东方 → 南二门右手电梯下负一 → 古代中国 → 逆向明清展厅看凤冠 → 再补人少展厅。
    📷 国博
    负一青铜器 / 凤冠特写 / 中庭纵深 / 文创区人像
  • 17:30–19:15
    天安门降旗：步行约 20–30 分钟安检。18:00 前到位；降旗约 18:54；亮灯约 19:10。
    📷 广场
    国旗杆纵深 / 亮灯后城楼夜景 / 纪念碑剪影
  • 19:30–22:00 · 可选
    798：打车约 55–60 分钟。太累可直接回酒店（打车约 40 分钟 / ¥20）。
DAY 2 · 琥珀

⑤ 8/28 周五 · 皇城 + 颐和园 + 夜景

步数最多一天 · 注意体能
体能提示：故宫 4h + 景山 + 颐和园 1.5h 很满。颐和园按精简线走，别恋战。
  • 06:20–09:00
    起床早餐 → 7:15 出发中山公园（约 55 分钟）→ 穿园 15–20 分钟 → 8:30 午门排队 → 9:00 入故宫。
  • 09:00–13:00
    故宫约 4 小时。
    中轴：午门 → 太和殿 → 中和 / 保和 → 乾清 / 交泰 / 坤宁 → 御花园 → 神武门出。余力再补一侧六宫。
    📷 故宫
    午门框景 / 太和殿对称 / 红墙人像 / 御花园光斑
  • 13:00–14:20
    景山：南门 → … → 万春亭 → 北门（约 70 分钟）。
    📷 王牌
    万春亭故宫全景鸟瞰
  • 14:30–17:00
    颐和园：打车约 40 分钟 / ¥22。只留 1.5h。
    精简：东宫门 → 仁寿殿 → 乐寿堂 → 佛香阁 → 长廊 → 十七孔桥外观 → 铜牛 → 新建宫门出。
  • 17:00–22:00
    什刹海（打车约 30 分钟 / ¥20）→ 太古里（地铁约 40 分钟）→ 回酒店（地铁约 55 分钟）。

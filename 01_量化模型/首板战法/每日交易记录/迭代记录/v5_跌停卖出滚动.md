# v5 · 跌停卖不出滚动（2026-07-29）

## 规则
- **9:35 跌停**：该时点无法卖出 → 跳过早盘价，等 13:15
- **13:15 跌停**：当日无法卖出 → 滚动到下一交易日（D3+）重新取 9:35 / 13:15
- 与原有「13:15 仍涨停则滚动」并存

## 实现
- `price_service.py`：`limit_down_price` / `is_at_limit_down`；`resolve_sell_day_prices` 接入跌停判断
- `enrich_trade_prices`：若已有卖出价落在跌停，自动作废并重解
- 手册 / UI 提示同步更新

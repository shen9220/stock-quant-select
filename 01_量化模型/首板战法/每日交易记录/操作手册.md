## 一、启动前端（浏览器查看/编辑）

```bash
cd /path/to/01_量化模型/首板战法/每日交易记录
python3 stock_UI.py
```

- 启动后自动打开浏览器（本机 `http://127.0.0.1:5050`，端口占用会顺延）
- **手机查看**：电脑与手机连同一 Wi-Fi，浏览器打开启动日志里的 `http://<电脑局域网IP>:<端口>`（服务已监听 `0.0.0.0`）

## 二、日常流程

| 步骤 | 做什么 | 说明 |
|------|--------|------|
| 1 | 运行 `python3 stock.py` | D0 涨停池选出 Top2，自动写入 `trades/{D1买入日}.json` |
| 2 | 保持 `python3 stock_UI.py` 运行 | **铁纪律**：交易日 **15:00 后自动**补全当日买卖价与盈亏；早盘手动点「收盘补全」**不算**完成，不挡盘后自动跑；进程若 15:00 后才启动会自动补跑 |
| 3 | 也可点顶栏「收盘补全」 | 手动触发同上逻辑 |
| 4 | 点「补全空值 / 强制重拉」 | 仅填空，或强制覆盖 |

手动命令：

```bash
python3 daily_close_job.py              # 补今天
python3 daily_close_job.py --date 2026-07-28 --force
```


## 三、交易时序与卖出规则

- **D0**：涨停选出日  
- **D1**：买入日，买入价 = **当天开盘价**；若**开盘一字/涨停买不进**：仍写入记录，买卖价留空并标注原因  
- **D2**：卖出日 

卖出规则：

1. **9:35**：记录早盘卖出价（全仓 / 半仓同价）  
2. **若开盘一字涨停**：9:35 **不卖**，等到 13:15  
3. **若 9:35 跌停**：该时点**卖不出**，跳过早盘，等 13:15  
4. **13:15 仍涨停**，或 **13:15 跌停**：当日卖不出，**滚动到 D3**（及之后）的早盘/午盘，规则同 D2  
5. **分批卖出总价** = `(9:35半仓价 + 13:15半仓价) / 2`

## 四、盈亏字段（8 列）

| 字段 | 公式 |
|------|------|
| 早盘总盈亏 | `(9:35价 - 买入价) / 买入价` |
| 午盘总盈亏 | `(13:15价 - 买入价) / 买入价` |
| 早盘总盈亏一半 | 早盘总盈亏 / 2 |
| 午盘总盈亏一半 | 午盘总盈亏 / 2 |
| 早盘分批盈亏 | `(9:35半仓价 - 买入价) / 买入价` |
| 午盘分批盈亏 | `(13:15半仓价 - 买入价) / 买入价` |
| 分批总盈亏 | 早盘分批盈亏 + 午盘分批盈亏 |
| 分批总盈亏一半 | 分批总盈亏 / 2 |

涨用红底、跌用黄底（参考记账表风格）。

## 五、UI 功能

- **搜索 / 按日期筛选**
- **新增 / 编辑 / 删除**
- **补全价格**：只填空字段  
- **强制重拉价格**：覆盖已有自动价（手工改过的也会被覆盖，慎用）
- **单行「补价」**：只重拉该行  
- **导出 CSV**
- **二板**：默认按买入日是否涨停自动判定，可在编辑里改成「是/否」

顶部统计卡分别汇总：早盘 / 午盘 / 分批盈亏合计与胜率、二板率。

## 六、存储格式

`trades/2026-07-28.json`（一天一个文件，数组内 1～N 条）：

```json
[
  {
    "id": 1,
    "date": "2026-07-28",
    "stock_code": "000001",
    "stock_name": "平安银行",
    "buy_price": 10.5,
    "sell_price_935": 10.8,
    "sell_price_1315": 10.6,
    "sell_price_half_935": 10.8,
    "sell_price_half_1315": 10.6,
    "sell_price_batch_avg": 10.7,
    "sell_date": "2026-07-29",
    "hold_days": 1,
    "pnl_morning": 2.86,
    "is_second_board": false,
    "rank": 1
  }
]
```

写入时自动备份到 `data/backups/`，保留约 14 天。

## 八、回填历史月份

```bash
cd 每日交易记录
python3 backfill_month.py --start 2026-07-01 --end 2026-07-27
# 仅补价：
python3 backfill_month.py --enrich-only
# 补齐 7/1、7/2（同花顺涨停池）：
python3 backfill_jul01_02.py
```

优先读取 `results/*_recommendations.md`；无文件的交易日用涨停池轻量 Top2。
分钟价优先 baostock 5 分钟 K（9:35 / 13:15）。

## 九、界面说明（优化后）

- **第一名 / 第二名 Tab**：默认第一名，互不混排  
- **月份切换**：顶栏下拉，统计与列表只看当月  
- **分批总盈亏** = 早盘分批/2 + 午盘分批/2  
- **本月三类盈亏卡**：早盘/午盘/分批，均按半仓口径汇总  
- **新增**：名称必填、代码可空（名称自动匹配代码）  
- **列表**：最新日期在上，默认 40 条/页  


**Q: 打开 UI 是空白？**  
先跑一次 `stock.py`，或在 UI 点「新增记录」。

**Q: 价格一直是 —？**  
分钟线接口偶发失败/延迟。等盘后再点「补全价格」，或手动填价（保存后自动重算盈亏）。

**Q: 旧路径 `首板战法/stock_UI.py`？**  
已改为跳转启动本目录脚本，建议直接进入 `每日交易记录` 运行。

**Q: 端口被占用？**  
脚本会从 5050 起自动找空闲端口，看终端打印的 URL 即可。

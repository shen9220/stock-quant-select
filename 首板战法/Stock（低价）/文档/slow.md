# slow.py 低价一进二选股逻辑

从前一交易日（D0）涨停池筛出首板，按**双轨偏好**打分并取 Top 2：  
① **低价活跃 ST** ② **创业板早封缩量**。  

**仅本地打印与落盘，不发送通知。**

## 与 stock.py 的差异

1. 强制含 ST（东财池缺 ST 时用新浪列表+腾讯 K 线补充）
2. 股价：ST ≤ 6 元；非 ST ≤ 12 元（覆盖创业板）
3. Top2 结构固定偏好：先 ST，再创业板
4. 无通知

```bash
python3 slow.py
python3 slow.py 20260716
```

---

## 交易时序

D0 选出 → D1 开盘半仓冲击二板 → D2 收盘前清仓。

> 70%/20% 为目标导向，非回测保证。

---

## 一、数据

| 源 | 说明 |
|----|------|
| 东财涨停池 | `ak.stock_zt_pool_em` |
| ST 补充 | 新浪 ST 列表 + 腾讯日 K（涨幅≥4.8% 且收盘≈最高） |

---

## 二、硬筛

| 条件 | 规则 |
|------|------|
| 首板 | D0 在池、再前一日不在池 |
| 板块 | 排除 688/92；保留主板/创业板/ST |
| 股价 | ST≤6；非ST≤12 |
| 封板时间 | ≤10:30；ST 补充无分时放行 |
| 炸板 | ≤1 |
| 换手 | ≥3%；非ST≤25%；ST≤45% |
| 流通市值 | 3亿–80亿 |
| 近似一字 | 封板≤09:25 且换手&lt;3% 剔除 |
| 板块助攻 | 同行业涨停≥2 |

---

## 三、双轨打分与 Top2

### ① 低价 ST 轨（排名优先占第 1）

偏好：放量活跃换手（约 15%–40%）+ 成交额 + 低价 + `*ST` 加成；压低趋势/基因权重（避免「西王类」凭趋势压过「萃华类」放量票）。

### ② 创业板轨（排名优先占第 2）

偏好：早封板 + 缩量（约 3%–10%）+ 接近 20% 涨幅；整体高于普通主板（避免「欢瑞类」主板早封压过「格林类」）。

### Top2 选取

1. 在 ST 候选中取得分最高 → 第 1  
2. 在创业板候选中取得分最高 → 第 2  
3. 若某一侧缺失，再按总分从其余候选补足  

---

## 四、输出

`results/{日期}_slow_recommendations.md`，无通知。

## 流程一句话

**（东财∪ST补充）∩首板∩价/换手/封板硬筛 → 双轨打分 → ①最佳ST + ②最佳创业板。**

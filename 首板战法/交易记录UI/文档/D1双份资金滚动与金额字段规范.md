# D1 / D2 交易日、资金与金额字段规范

更新：2026-11-11。本文以用户最新确认内容为准，同时适用于 D1 和 D2。

**本次覆盖旧定义：D2 不再沿用 D0 买价；平盘改为早盘多卖一手；两笔资金不再永久各自以2万独立滚动；每次买入均受当时总资产50%的硬上限约束；所有涨停池、候选及结果只计首次涨停，连板不计入。**

旧文档中“D2暂不改”“平盘少卖”“所有现金固定分成两条永不合并的2万元链”“全市场查阅保留连板”均已失效。历史原始行情、推荐记录保留作审计，不因规范更新伪造或删除既往交易。

## 1. 统一交易日定义

所有相邻日期按交易所交易日历推进，不能用自然日、星期一至五简单替代。停牌是个股状态，不改变全市场 D0/D1/D2 标签。

| 标签 | 定义 | D1模式 | D2模式 |
|---|---|---|---|
| D0-2 | 涨停日的前一个交易日，检查是否已涨停 | 已涨停则剔除；未涨停才允许首板入池 | 相同 |
| D0-1 | 本次首次涨停日 | 复盘选股、排序 | 同一信号与排序 |
| D0 | 首次涨停后的第一个交易日 | 买入日 | 不买入 |
| D1 | D0的下一个交易日 | 原定卖出日 | 买入日 |
| D2 | D1的下一个交易日 | 已退出或继续处理顺延 | 原定卖出日 |

例如连续交易日：周四D0-2、周五D0-1、周一D0、周二D1、周三D2。节假日以真实日历为准。用户示例中的11.1等日期用于说明资金先后关系，不作为实际交易日历。


具体例：2026-11-09为D0-1涨停日，D0-2必须取交易所上一开市日2026-11-06；11-07/11-08休市，不能查询作校验日。计算11-06涨跌时，其前收盘基准取11-05。D0为11-10，D1为11-11，D2为11-12。行政调休上班不自动等于证券交易所开市，全年都只按交易所日历推进。缺数据诊断必须写明实际日期及缺少的字段，区分D0-2行情、前收盘基准、D0-1行情和涨停规则，不笼统归为D0-2缺失。

### 首板约束：所有入口一致

- D0-1必须涨停，D0-2必须能够证明未涨停。
- D0-2已涨停的股票，不进入本系统涨停池、候选、排名及新生成的result；不是仅从明细隐藏，也不是保留在“全市场查阅”中。
- 板块是否ST/主板/创业板/科创等与是否首板分开判断；查阅页可保留各板块的首次涨停，各模型自身板块限制继续执行。
- 缺少D0-2行情不等于未涨停；缺证据标记“待核实”，不放入已证明首板结果。
- 涨跌停价按板块、ST状态及昨收的价格档位取整计算，不能仅以固定9.5%阈值判断所有品种。
- 原始全市场行情缓存可以保留连板观测值供审计，但它不是本系统合格涨停池/结果。

## 2. D1与D2买卖原则

### D1

D0-1首次涨停 → D0开盘买入 → D1分批卖出。两批时点固定为9:35、13:35。

### D2

D0-1首次涨停 → D0不买 → D1开盘买入 → D2分批卖出。两批时点同样固定为9:35、13:35。

D2使用D1真实开盘价、D1可用现金和总资产上限计算股数。禁止直接使用D0买价，也不能使用旧实现中D2开盘“重新买入”的字段。

### 买入停牌与卖出顺延

- 买入日停牌：按同一信号日、同一模型的候选排名选择下一名，再检查其是否可买。不是把原股票改成复牌后再买，也不能跨模型取候选。
- 后续候选不足或无法证明停牌/有效开盘行情时，保留未买原因；缺价不能冒充停牌以随意换股。
- 卖出日停牌：持仓保留，顺延至复牌交易日，仍在9:35、13:35分别尝试对应批次。
- 某批在其卖点涨停、跌停或缺少有效报价：不确认该批卖出，不释放该批持仓与回款；顺延到后续同一时点，直到具备可执行价格。
- 两批独立顺延。午盘已卖不代表早盘自动卖出；已卖股数不能重复出售。
- 13:35缺价保持空值，禁止以13:15替代；原单点及13:15字段保留后台审计。

## 3. 账户、两笔资金与50%硬上限

每个 `模型 × 名次 × D1/D2 × 资金账期` 独立账户，不能互相借款或混算利润。

- 2026年1—10月账户初始10万元；11月起重新以4万元起算；2026年前金额暂空。
- 4万元初始化为两份2万元；10万元阶段对应两份5万元。两份用来跟踪交替买入的两笔持仓及其卖出状态，不代表每笔永远只能使用原始2万元，也不代表永远使用上一笔全部回款。
- 正常最多同时占用两笔持仓。某笔未全部退出，保留剩余股数；两笔均被占用时暂停新增买入。
- **每次新买入预算 `L = min(当时可用现金, 当时账户总资产 × 50%)`。这是统一硬上限，任何资金情形都不能例外。**
- 例如可用现金达到总资产80%，新买仍只能使用总资产50%；一手取整后实际投入还会更少。
- 总资产采用买入时点已有现金＋原持仓当时可得市值；本次模拟用开盘时点估值。缺估值时不假设总资产、不凭成本代替市值计算上限。
- 买入余款和未使用现金可合并计算可用余额。资金转移必须留事件记录，不把旧持仓市值转成可用现金。
- 当天卖出回款仍按策略锁定；该笔全部退出后的下一交易日才可重新用于买入。部分退出尚未完成的回款不抢先投入新笔；原未投入现金与卖出回款分开记录。
- 整体完全空仓后，在资金解锁日把全部现金重新平分；下一次买入仍执行上述50%上限，另一半等待后续交易日机会。
- 资金不足一手只跳过当日新买，不取消原持仓当天的卖出任务；不注入额外资金。

### 情况一：买不起，旧仓完整退出

当日推荐价230.30元，预算2万元；一手需23030元，不能买入。前一天的旧仓继续卖出。当日收盘完全空仓，账户现金总额41255元。

下一次出现合格新票时，账户按总额重新平分：预算上限41255/2=20627.50元。按这份预算取整手，另一份现金继续等待。不是继续固定使用旧2万元，也不能一次买满41255元。

### 情况二：买不起，旧仓未完整退出

买不起当天的新票，同时旧持仓在9:35或13:35涨跌停/停牌，继续持有。账户未完全空仓，不能把旧仓市值当成现金，也不能盲目把可用余额全部买满。

用户确认示例：总资产39000元、可用现金21837元、股价3.50元。

- 可用21837元包含空置资金及旧笔买入后的余款；它不是新的买入预算。
- 本次预算=min(21837,39000×50%)=19500元。
- 可买55手=5500股，实际成本19250元。
- 全账户买入后现金=21837−19250=2587元（假定无其他日内现金变化）；旧仓市值继续单独计入总资产。
- 不能用21837元买6200股。旧仓仍按规则尝试退出，不能为了腾额度虚构卖出。

## 4. 整手与奇数手拆卖

适用的主板/创业板等本轮模拟按一手100股：

`可买手数 = floor(L / (买入价 × 100))`

`初始股数Q = 可买手数 × 100`

`实际买入成本M = Q × 买入价B`

`本次预算余款U = L − M`

例：L=20000、B=45.20，买4手400股，成本18080，预算余款1920。未配置交易单位的品种可以查阅但不套用错误整手规则虚构成交。

### 9:35按当日涨幅判拆分

- 判断基准是对应日盘面昨收，不是本笔买入价。
- 当日9:35涨幅 **≥0%**：早盘卖较多手；**<0%**：早盘卖较少手。
- N手时：非负早盘 `ceil(N/2)` 手，负值早盘 `floor(N/2)` 手；午盘为余下手数。
- 300股（3手），当日涨幅1%或恰好0%：早盘200股、午盘100股。
- 300股，当日涨幅−1%：早盘100股、午盘200股。
- 用户描述的“300手卖200/100”示例在本规范按300股解释；如果实际为300手=30000股，应为150手/150手。
- 1手非负时早盘全卖，负值时留午盘全卖；不安排的批次不虚构成交。
- 原定卖出日停牌，使用复牌后第一个可观测9:35的当日涨幅拆分；已完成拆分后，即使某批顺延，也不重新拆分、重复计数。
- 缺9:35或昨收时无法确定奇数手拆分，标记缺口，不用后来成交价反推原决策。

## 5. 金额、比例和回款

### 术语

| 字段 | 定义 |
|---|---|
| 当日总金额 | 买入前时点账户现金＋旧仓当时市值；保存时点 |
| 当日可用金额 | 买入前未受锁定的账户现金，可以大于50%预算 |
| 买入预算（后台/提示） | min(可用现金, 总资产50%) |
| 持仓金额 | 本笔剩余股数×原买入价，即剩余成本 |
| 持仓市值（后台） | 剩余股数×快照当时真实估值价 |
| 未持仓金额（逐笔追踪列） | 该笔预算余款U＋该笔已卖回款；是逐笔预算追踪值，不是额外资产，不能逐行加成账户可用现金 |
| 账户现金（后台/快照） | 全账户实际现金，独立记录锁定与可用状态；跨笔使用余款按现金转移事件守恒 |
| 卖出金额 | 本笔实际卖出股数×对应实际卖价的累计回款，包含本金 |
| 分批利润 | 本笔实际卖出股数×买卖价差之和，不包含未投入的余款 |
| 收盘后金额（逐笔列） | 该笔完整退出后的预算追踪值U＋本笔回款；未全部退出保持空值，不等同账户总资产 |
| 月末/期末汇总金额 | 该账户期末实际现金＋剩余持仓市值，不把逐笔追踪金额重复相加 |

每个金额明确账户或逐笔范围及快照时点。当前剩余成本/回款与买入日资产快照不能混称同一时点的数据。

### 实际股数决定比例

初始股数Q、买价B、实际卖出股数q、卖价S：

- 时点整批盈亏 `r=(S/B−1)×100%`。
- 时点分批/半仓盈亏贡献 `w=(q/Q)×r`。
- 时点分批/半仓利润 `P=q×(S−B)`。
- 分批盈亏=已成交早午两批w之和；分批利润=早午P之和=实际投入成本M×已实现分批收益率。
- 卖出回款=Σ(q×S)，含本金；缺价或未成交不先计利润、回款、股数减少。
- 两批股数相等才有 `(早盘整批盈亏+午盘整批盈亏)/2`。奇数手不能机械取平均。
- 月表/对比“半仓”保留作分仓列名，实际值按真实股数权重，未必恰好50%。

9880.30和10108.10是回款，不是利润：各成本10000时，利润−119.70、+108.10，合计−11.60。预算20000且无余款时完结金额19988.40。

18080×0.1%=18.08是利润；回款18098.08，预算余款1920，逐笔完结金额20018.08。

本轮不含未配置的佣金、税费。历史股数是按本规范模拟，不标成券商真实成交。

## 6. 快照、跨月与账期

- 总资产=现金＋剩余持仓市值；回款已经属于现金，不重复再加卖出金额或逐笔收盘后金额。
- 事件时点为9:35/13:35；任务10:00/14:00更新时不得把更新时间冒充成交时间。
- 卖出事件按**实际卖出日期**归属月度。11月30日买、12月1日卖：11月底保留持仓市值，12月计已实现利润。
- 月初总金额承上月末总金额；11月账期初始化4万元。月末总金额取最后可得资产快照，含持仓市值，缺估值则空值并提示。
- 10万元与4万元分成两个独立审计账期。跨重置日旧仓继续留在旧账期追踪，不伪造清仓，也不混入新4万元账户。旧账期尾部事件保留API审计；新账期页面不把旧账期回款当新账户收益。
- 已实现利润不必等于期末资产减期初资产，因为还有未实现浮盈亏及账期资金调整。
- 同一输入重放必须幂等；卖出股数、回款及现金不可重复入账。

### 本轮冻结公式

设账户当日本金 C，单票买入本金 I=C×50%，原始早午涨跌幅 r_am、r_pm（百分数）。

| 指标 | 公式 |
|---|---|
| 早盘盈亏 | (实际9:35卖价−买入价)/买入价×100 |
| 午盘盈亏 | (实际13:15卖价−买入价)/买入价×100 |
| 早盘半仓盈亏 | r_am÷2 |
| 午盘半仓盈亏 | r_pm÷2 |
| 分批盈亏 | r_am÷2+r_pm÷2；只有一边时仅取该边÷2 |
| 分批半仓盈亏 | (早盘半仓盈亏+午盘半仓盈亏)÷2，即分批盈亏÷2；缺失边不贡献利润 |
| 早/午分析利润 | I×对应半仓盈亏÷100 |
| 分批半仓利润 | I×分批半仓盈亏÷100，不直接采用早午分析利润之和 |
| 列表汇总本金 | I+该笔分批半仓利润 |
| 账户日末本金 | C+同日该名次线分批利润合计，仅供账户滚动；与列表单票汇总本金区分 |

用户样本：C=100000，I=50000，买价2.5，早价2.75、午价3；早午盈亏10%/20%，半仓5%/10%，分批盈亏15%，分批半仓7.5%，分批利润3750，列表汇总53750，账户结转103750。

涨跌停无法成交仍复用现有按时点独立顺延流程。展示使用原记录实际成交价格及日期，不将封板价直接作为已成交收益；缺价保留待卖/缺价状态。未触发补价或交易数据迁移。

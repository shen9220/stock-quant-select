## 二、日常流程

| 步骤 | 做什么 | 说明 |
|------|--------|------|
| 1 | 运行 `python3 stock/stock.py` 或 `python3 slow/slow.py` 或 `python3 up/up.py` | D0 选出 Top2，写入对应 `{程序}/trades/` |
| 2 | 保持 `python3 stock_UI.py` 运行 | **铁纪律**：交易日 **15:00 后自动**补全当日买卖价与盈亏；早盘手动点「收盘补全」**不算**完成，不挡盘后自动跑；进程若 15:00 后才启动会自动补跑 |
| 3 | 也可点顶栏「收盘补全」 | 手动触发同上逻辑 |
| 4 | 点「补全空值 / 强制重拉」 | 仅填空，或强制覆盖 |

手动命令：

```bash
python3 jobs/daily_close_job.py              # 补今天
python3 jobs/daily_close_job.py --date 2026-07-28 --force
```


## 三、交易时序与卖出规则

- **D0**：涨停选出日（**禁止**用 D0 开盘价或收盘价当买入价）  
- **D1**：买入日，买入价 = **D1 当天开盘价**（唯一合法口径）；若**开盘一字/涨停买不进**：仍写入记录，买卖价留空并标注原因  
- **D2**：卖出日  

> **铁律**：收盘补全 / 强制重拉 / 15:00 自动补价，写入的买入价必须是 D1 开盘价。详见 `../IRON_RULES.md`。 

卖出规则：

1. **9:35**：记录早盘卖出价（全仓 / 半仓同价）——必须是 **09:35 分钟价**，禁止用开盘价顶替  
2. **13:15**：记录午盘卖出价——必须是 **13:15 分钟价**，禁止用收盘价顶替  
3. **若开盘一字涨停**：9:35 **不卖**，等到 13:15  
4. **若 9:35 跌停**：该时点**卖不出**，跳过早盘，等 13:15  
5. **13:15 仍涨停**，或 **13:15 跌停**：当日卖不出，**滚动到 D3**（及之后）的早盘/午盘，规则同 D2  
6. **分批卖出总价** = `(9:35半仓价 + 13:15半仓价) / 2`  
7. 分钟线取不到时：**留空**待补，绝不写开盘/收盘错价（见 `../IRON_RULES.md`）

## 四、盈亏字段（8 列）

| 字段 | 公式 |
|------|------|
| 早盘总盈亏 | `(9:35价 - 买入价) / 买入价` |
| 午盘总盈亏 | `(13:15价 - 买入价) / 买入价` |
| 早盘总盈亏一半 | 早盘总盈亏 / 2 |
| 午盘总盈亏一半 | 午盘总盈亏 / 2 |
| 早盘分批盈亏 | `(9:35半仓价 - 买入价) / 买入价` |
| 午盘分批盈亏 | `(13:15半仓价 - 买入价) / 买入价` |
| 分批总盈亏 | 早盘分批盈亏 + 午盘分批盈亏 |
| 分批总盈亏一半 | 分批总盈亏 / 2 |

涨用红底、跌用黄底（参考记账表风格）。

## 五、UI 功能

- **搜索 / 按日期筛选**
- **新增 / 编辑 / 删除**
- **补全空值**：只填空字段；若已有买入价疑似 D0 开/收错写，会自愈纠正为 D1 开盘价  
- **强制重拉**：覆盖为 D1 开盘价及卖出价（手工改过的也会被覆盖，慎用）
- **收盘补全 / 15:00 自动**：今日买入价**强制**按 D1 开盘价重写
- **单行「补价」**：只重拉该行  

- **导出 CSV**
- **二板**：默认按买入日是否涨停自动判定，可在编辑里改成「是/否」

顶部统计卡分别汇总：早盘 / 午盘 / 分批盈亏合计与胜率、二板率。

## 六、存储格式

`trades/2026-07-28.json`（一天一个文件，数组内 1～N 条）：

```json
[
  {
    "id": 1,
    "date": "2026-07-28",
    "stock_code": "000001",
    "stock_name": "平安银行",
    "buy_price": 10.5,
    "sell_price_935": 10.8,
    "sell_price_1315": 10.6,
    "sell_price_half_935": 10.8,
    "sell_price_half_1315": 10.6,
    "sell_price_batch_avg": 10.7,
    "sell_date": "2026-07-29",
    "hold_days": 1,
    "pnl_morning": 2.86,
    "is_second_board": false,
    "rank": 1
  }
]
```

写入时自动备份到 `data/backups/`，保留约 14 天。

## 八、回填历史月份

> **铁纪律**：执行任何回填前必须先阅读 [`00_项目必读/行情数据拉取规范.md`](../../00_项目必读/行情数据拉取规范.md)。  
> 存在 `data/BACKFILL_PAUSED` 时批量 CLI 回填会拒绝启动。  
> **分头行动（三条线，倒序优先）**：`03:00`+`16:00` **Baostock 倒序 7→1** ↔ `18:30` 正序补洞（THS→Baostock→腾讯）；日约 6–9 天。  
> CLI **禁止** `--source baostock` 与 `workers>1`；封禁看 `data/BAOSTOCK_PAUSED`。

```bash
cd 每日交易记录

# 状态
python3 jobs/baostock_backfill_scheduler.py --status   # 03:00 / 16:00 倒序优先
python3 jobs/stock_backfill_scheduler.py --status      # 18:30 正序补洞

# stock 2025 单个月份（腾讯，推荐手动补洞）
export DISABLE_BAOSTOCK=1
python3 ../stock/scripts/backfill_stock_year.py --year 2025 --months 2025-03 --source tx --records-only

# slow/up 历史（暂停解除后）
python3 jobs/backfill_slow_up_historical.py --months 2025-01 --program slow --commit
```
旧命令（仍可用，须遵守规范）：

```bash
python3 backfill_month.py --start 2026-07-01 --end 2026-07-27
python3 backfill_month.py --enrich-only
python3 backfill_jul01_02.py
```

优先读取 `results/*_recommendations.md`；无文件的交易日用同花顺首板池 Top2。  
分钟价优先新浪 1 分钟 → 腾讯日线兜底（**非** baostock 批量扫描）。

## 九、界面说明（优化后）

- **第一名 / 第二名 Tab**：默认第一名，互不混排  
- **月份切换**：顶栏下拉，统计与列表只看当月  
- **分批总盈亏** = 早盘分批/2 + 午盘分批/2  
- **本月三类盈亏卡**：早盘/午盘/分批，均按半仓口径汇总  
- **新增**：名称必填、代码可空（名称自动匹配代码）  
- **列表**：最新日期在上，默认 40 条/页  


**Q: 打开 UI 是空白？**  
先跑一次 `stock.py`，或在 UI 点「新增记录」。

**Q: 价格一直是 —？**  
分钟线接口偶发失败/延迟。等盘后再点「补全价格」，或手动填价（保存后自动重算盈亏）。

**Q: 旧路径 `首板战法/stock_UI.py`？**  
已改为跳转启动本目录脚本，建议直接进入 `每日交易记录` 运行。

**Q: 端口被占用？**  
脚本会从 5050 起自动找空闲端口，看终端打印的 URL 即可。

- 卡片居中、hover 上浮；Tab/按钮轻微 3D 阴影

- 顶部盈亏：赚红亏绿（A 股习惯）

## 2. 盈亏色阶
| 条件 | 颜色 |
|------|------|
| ≥ 10% | 深红 |
| ≥ 5% | 浅红 |
| -5% ~ +5%（不含端点按区间） | 无底色 |
| ≤ -5% | 浅黄 |
| ≤ -10% | 深黄 |

## 3. 开盘涨停不买入
- 买入日开盘价触及涨停 → 不记录
- 历史清洗：`purge_open_limit_buys`（例：九安医疗 2026-07-20 开盘即涨停）
- 同步/补价时自动跳过或删除

## 4. 表头顺序
`ID｜买入日期｜代码｜名称｜买入价｜早盘卖出价｜早盘盈亏｜午盘卖出价｜午盘盈亏｜早盘半仓价｜早盘半仓盈亏｜午盘半仓价｜午盘半仓盈亏｜分批总价｜分批总盈亏｜卖出日期｜持有天数｜二板｜分批半仓盈亏｜早盘半仓盈亏｜午盘半仓盈亏｜操作`

说明：末尾两个「早/午盘半仓盈亏」对应全仓盈亏÷2 列（`pnl_morning_half` / `pnl_afternoon_half`）；中间同名对应半仓卖出价盈亏。

## 5. 顶部累计口径
- 分批胜率 = 分批半仓盈亏胜率
- 早盘盈亏累计 = Σ 早盘半仓盈亏（÷2 列）
- 午盘盈亏累计 = Σ 午盘半仓盈亏（÷2 列）
- 分批盈亏累计 = Σ 分批半仓盈亏

## 6. 合计行与排序
- 表头下合计行：盈亏列求和，其余 —
- 盈亏相关表头支持点击正倒序

## 7. 补价行为
- 行内「补价」：只填空/遗漏，已有值不动（`force=false`）
- 顶栏「强制重拉」：覆盖重算

## 8. 全年回填
- 脚本：`backfill_year_2026.py`（默认 7→1 月倒序）
- 数据：同花顺首板池 + baostock 成交额 Top2 + 补价

# v9 · 卖出价必须是 09:35 / 13:15（2026-10-14）

## 事故

今日四程序早盘卖出价写成了**当日开盘价**，午盘部分写成了**收盘价**，不是真实 9:35 / 13:15。

例（stock 莱美药业 卖出日 2026-10-14）：

| 栏位 | 错写 | 真实分钟 |
|------|------|----------|
| 9:35 | 6.71（=开盘） | **7.59** |
| 13:15 | 7.9（=收盘，且恰为涨停） | **7.9** |

## 根因

`price_service.get_minute_price` 在新浪/baostock 分钟线失败时，用日线兜底：

- `09:xx` → `ohlc["open"]`
- 其它 → `ohlc["close"]`

收盘补全写入后，`force=False` 不再覆盖。

## 修复

1. **删除**开盘/收盘分钟兜底；取不到返回 `None`
2. `enrich_trade_prices`：检测「9:35=开盘」指纹 → 自愈重解
3. `daily_close_job`：今日为卖出日 → `force` 重拉真分钟价
4. `fix_sell_prices.py` 批量订正
5. 规范写入 `IRON_RULES.md` / 操作手册 / 行情拉取规范

## 订正时顺带按规则滚动的例子

- 莱美药业：真 13:15=7.9 触及涨停 → 按规则滚到下一交易日（卖出价暂空）
- 广电网络：真 9:35 跌停 → 跳过早盘，只留 13:15

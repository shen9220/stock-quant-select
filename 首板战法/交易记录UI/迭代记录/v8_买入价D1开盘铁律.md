# v8 · 买入价必须是 D1 开盘价（2026-10-13）

## 事故

点击「收盘补全 / 补全空值 / 强制重拉」后，`stock` 买入价写成了 **D0 开盘价**（一字板时等于 D0 收盘），不是 D1 开盘价。

已确认错写 4 条：

| 程序 | 买入日 | 代码 | 错价(D0开) | 正确(D1开) |
|------|--------|------|------------|------------|
| stock | 2026-10-12 | 600127 金健米业 | 13.8 | 16.42 |
| stock | 2026-10-12 | 300821 东岳硅材 | 15.3 | 17.8 |
| stock | 2026-10-13 | 300006 莱美药业 | 6.56 | 6.8 |
| stock | 2026-10-13 | 301052 果麦文化 | 25.69 | 31.24 |

同日 `slow` / `up` / `stock_updata` 买入价正确（早盘留空，收盘才补 D1 开）。

## 根因

1. `stock.py` 调用 `upsert_from_stock_py(records)` 默认 `auto_enrich=True`，过早取价  
2. 竞价前新浪「今开」不可靠，易 residual 成 D0 开盘  
3. 收盘补全 UI 传 `force=False`，已有错价不再覆盖  

## 修复

1. 数据：上述 4 条已改为 D1 开盘并重算盈亏  
2. `stock.py`：`auto_enrich=False`  
3. `price_service`：9:25 前不用新浪今开  
4. `enrich_trade_prices`：若现价≈D0 开/收且≠D1 开 → 自愈纠正  
5. `daily_close_job`：今日买入强制 `enrich(force=True)` 重写买价  
6. 规范：`IRON_RULES.md` / 操作手册 / 行情拉取规范 写死口径

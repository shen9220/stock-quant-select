# 历史涨停池与买卖竞价取数规范（跨模型共用）

> 日期：2026-10-29  
> 状态：**权威**（新模型必须按本文调用，禁止再「只打东财涨停池」）  
> 可调用门面：`01_量化模型/共享取数/lib/hist_market_data.py`  
> 实现源：Stock V1 主板/创业板夜班已验证代码（见文末路径表）

---

## 0. 为什么要有本文

Stock V2 历史回补曾出现「几乎全日空仓」：根因是预筛只调 `ak.stock_zt_pool_em`，**历史日经常直接空表**，连候选都进不了，更谈不上竞价量能。

Stock V1 主板/创业板能补 2026 日记录，是因为：

1. **磁盘缓存** `zt_pool_cache/{YYYYMMDD}.json`  
2. **多源回退**：东财失败 → 同花顺涨停池  
3. **买卖价另轨慢补**（搜狐/腾讯/新浪等），走 `platform_gate` 配额，不与涨停池绑死

本文把上述办法固化为**标准三阶段倒置流水线**，供 V2 / 新模式直接复用。

---

## 1. 铁律

1. **禁止**新模型自己再写一套「只调东财涨停池」；统一 `hist_market_data.fetch_limit_up_pool`。  
2. **倒置过滤（必须）**：  
   - Stage A：先拿到涨停**代码池**（允许换手/成交额暂时为 0）  
   - Stage B：再按需补换手 / 封板时间 / 成交额  
   - Stage C：再取 D1 买入竞价（或开盘估价）与卖出价  
   - **禁止**在 Stage A 因「换手率为 0 / 缺字段」直接判整日无池。  
3. **空池与缺字段要分开**：  
   - `pool_empty`：源都失败、真无涨停名单  
   - `fields_sparse`：有代码但缺换手 → 进 Stage B，不是 NO_TRADE  
4. **一切外网请求走 `platform_gate`**；限额见 `每日交易记录/data/platform_rate_limits.json`（全库软上限：多数平台 ×80%；tdx ×70%）。可读总表：`最新一进二/文档存放/取数平台与限流规范.md`。  
5. **禁止**用 0 / 今开冒充「已验证的 9:25 竞价量额」；缺真量标注 `DATA_UNAVAILABLE` / `BACKFILL_OPEN`（仅开盘估价）。  
6. baostock 默认 `DISABLE_BAOSTOCK=1`，不作为主源。

## 2. 标准流水线（倒置）

```
D0 交易日
  │
  ├─ Stage A  涨停池名单
  │     磁盘缓存 → 东财 em → 同花顺 ths
  │     产出：代码 + 名称（+ 能拿到的涨跌幅等）
  │     换手缺失 ≠ 失败
  │
  ├─ Stage B  字段补齐（按模型需要）
  │     日线换手 / 成交额 / 流通市值推算换手
  │     可选：封板时间、连板（若源有）
  │     再应用「换手带」等硬过滤
  │
  └─ Stage C  买卖与竞价
        买：D1 开盘估价（sohu / 腾讯日线）或 09:25 真竞价（mootdx，占 tdx）
        卖：次日 09:35 / 13:15 等（sina / 腾讯分钟）
```

### 2.1 Stage A — 涨停池

| 优先级 | 源 | 函数 | 说明 |
|--------|-----|------|------|
| 0 | 磁盘 | `load_zt_disk` / 缓存命中 | `每日交易记录/data/zt_pool_cache/{date8}.json` |
| 1 | 东财 | `fetch_zt_em` ← `ak.stock_zt_pool_em` | 近端字段最全；**历史常空** |
| 2 | 同花顺 | `fetch_zt_ths` | 历史名单可用；换手常为 0 → 交 Stage B |

门面：

```python
from hist_market_data import fetch_limit_up_pool
df = fetch_limit_up_pool("20260105")  # YYYYMMDD
# df 至少含：代码、名称；换手率可能全 0
```

### 2.2 Stage B — 换手等字段

在**已有代码列表**上逐票补，不要回过头否定 Stage A：

| 字段 | 推荐来源 | 备注 |
|------|----------|------|
| 换手率 | 东财/腾讯日线 `换手率`；或 成交额/流通市值 | 守平台配额，串行 |
| 成交额 | 同日日线 | |
| 首次封板 | 东财涨停池富字段（仅近端常有） | 历史可缺，模型自行降级 |

门面：

```python
from hist_market_data import enrich_turnover
df2 = enrich_turnover(df, "20260105")
# 再由模型做 5%～20% 换手带等过滤
```

### 2.3 Stage C — 买入 / 卖出 / 竞价

| 用途 | 推荐 | 门面 / 实现 | 配额平台 |
|------|------|-------------|----------|
| D1 买价≈开盘 | 搜狐 hisHq / 腾讯日线开盘 | `estimate_buy_open` → `board_buy_sources` | sohu / tencent |
| D1 09:25 真竞价量价 | mootdx 分笔 | `stock_v2.fetch_mootdx_auction_0925` | **tdx**（见通达信规范） |
| 卖价 09:35 / 13:15 | sina / 腾讯分钟 | board_sell 轨道 | sina / tencent |

**选用规则**

- 只要「开盘估价 / 看板买价」→ 用 sohu/腾讯，**不要占 tdx**。  
- 要「竞价量、竞价额、竞价换手」做评分 → 必须 mootdx，且遵守 `通达信竞价取数安全规范.md`（11:00–14:30 历史窗、日/小时双软上限）。

```python
from hist_market_data import estimate_buy_open, estimate_sell_prices
buy = estimate_buy_open("002931", "2026-01-06")   # D1
sell = estimate_sell_prices("002931", "2026-01-07")  # 卖出日
```

## 3. 与各模型的关系

| 模型 | 应如何用 |
|------|----------|
| Stock V1 主板/创业板 | 已按 Stage A（board_night）+ Stage C 买/卖慢补在跑；勿另起炉灶 |
| Stock V2 | 预筛 Stage A 必须走本门面；换手带放到 Stage B；竞价评分走 Stage C mootdx |
| 新模式 / 未来模型 | 只 import `hist_market_data`；过滤规则写在自己模型里 |

时间窗错峰（沿用 V1/V2 已约定）：

| 任务 | 时段 | 平台 |
|------|------|------|
| V2 历史竞价 | 11:00–14:30 | tdx |
| 主板 board_night / board_price | 15:30–04:50 | sohu/tencent/sina |
| 早盘通知 | 08:40–09:29 | 腾讯快照等（不占 tdx 历史配额） |

## 4. 缓存与「假空」

| 现象 | 正确处理 |
|------|----------|
| 东财返回空、同花顺有代码 | 用同花顺名单，标 `source=ths`，换手交 Stage B |
| 磁盘已有仅代码、换手全 0 | **视为 Stage A 成功**；不要当成 pool_empty |
| 磁盘写入了「真·空表」 | 仅当所有源都失败；写 `source=none` 便于日后强制刷新 |
| 强制刷新 | `fetch_limit_up_pool(date8, force_refresh=True)` 跳过稀疏磁盘 |

## 5. 调用示例（新模型最小骨架）

```python
import sys
sys.path.insert(0, "…/01_量化模型/共享取数/lib")
from hist_market_data import (
    fetch_limit_up_pool, enrich_turnover,
    estimate_buy_open, estimate_sell_prices,
)

date0 = "20260105"          # D0 涨停日 YYYYMMDD
d1 = "2026-01-06"           # D1 买入日

pool = fetch_limit_up_pool(date0)           # Stage A
pool = enrich_turnover(pool, date0)         # Stage B
# … 模型自己的硬过滤（换手带、剔连板等）…
for code in pool["代码"]:
    buy = estimate_buy_open(code, d1)       # Stage C 估价
    # 若需要真竞价量能：再调 stock_v2.fetch_mootdx_auction_0925（占 tdx）
```

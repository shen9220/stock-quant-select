## 2. 调度与限流摘要

| 主题 | 规则 |
|------|------|
| 作业总窗 | **每日统一** **10:00 → 次日 00:00**；过零点硬停，第二天 10:00 续；**00:00–10:00** 全体安静（护早盘 07–10） |
| 平台清单 | 正式模型占用见 `交易记录UI/data/production_platform_reserve.json`；回补入口 `BACKFILL_RESPECT_RESERVE=1` |
| 软上限 | 小时到软上限即停；有日上限则日到停；无日上限只按小时；次日/下小时续跑 |
| 首板 | D0 必须涨停，D0-1 必须不是涨停。连板跳过。D1 买入，D2 卖出。前一日池里没有这只，不能当成首板 |
| 优先级 | **V2 > V1** |
| 新平台 | 先调研再登记 `platform_rate_limits.json` |

详情：`stock-V2/Stock-V2（一进二）/文档存放/取数平台与限流规范.md`；时间窗实现 `交易记录UI/lib/backfill_window.py`

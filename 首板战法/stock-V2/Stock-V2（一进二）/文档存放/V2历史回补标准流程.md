## 0. 目标与非目标

**目标**

- 按「倒置流水线」补 2026-01-01 → 最新交易日的 V2 可复核样本。  
- 区分 **PASS / FAIL / MISSING**，禁止把缺数当成不合格而删候选。  
- 真 09:25 竞价走 **tdx/mootdx**；无真量则标 `AUCTION_MISSING` 或估价模式 `BACKFILL_OPEN`（**不得用全天量冒充竞价量**）。

**非目标**

- 不改 A/B 评分权重、换手带、路径门槛。  
- 不在未验证前宣称「全年完整竞价回测已完成」。

## 1. 标准五步（与补全规范对齐）

| 步 | 名称 | 做什么 | 本仓入口 | 平台 |
|----|------|--------|----------|------|
| 1 | 建涨停候选池 | 只拿名单；**不用换手/竞价过滤** | `hist_market_data.fetch_limit_up_pool` ← 磁盘/EM/ths | eastmoney / ths |
| 2 | 真首板核定 | D0 涨停、D-1 非涨停、连板=1、板块/ST | `stock_v2.build_d0_universe` | 日线：tencent / eastmoney |
| 3 | 补日线因子 | 换手、量额、涨跌幅等 | `enrich_turnover` + 日线 | eastmoney / tencent；（baostock 待解禁） |
| 4 | 补次日竞价 | D1 09:25 价量额 | `stock_v2` + `--backfill` / `scripts/stock_v2_hist_daily.py` | **tdx**（11:00–14:30） |
| 5 | 执行 V2 条件 + 报告 | 仅数据齐全的因子参与硬过滤；输出合格/不合格/缺失 | `results/*_recommendations.json` + trades | — |

状态机（每字段）：

| 状态 | 含义 | 处理 |
|------|------|------|
| PASS | 有真数且过门槛 | 保留 |
| FAIL | 有真数但不过门槛 | 策略排除 |
| MISSING / REVIEW_REQUIRED | 无字段或无法确认 | **留在待补池**，不删候选 |
| AUCTION_MISSING | 无真 09:25 量价 | 不进「完整竞价回测」集合 B |
| BACKFILL_OPEN | 仅有开盘估价 | 可看路径/分数，**不得冒充 VERIFIED 竞价量** |

## 2. 运行入口（必须走这些）

### 2.1 日常 / 倒序历史竞价

```bash
# cron：交易日 11:00（已挂）
scripts/stock_v2_hist_daily_entry.sh

# 人工全力（仍守 tdx 软上限；可 IGNORE_WINDOW=1）
IGNORE_WINDOW=1 WAIT_HOUR_RESET=1 scripts/stock_v2_hist_all_then_pages.sh
```

约束（详见《取数平台与限流规范》）：

- **作业总窗 10:00–次日 02:00**；V2 未全部完成前不启 V1 回补。  
- tdx 现行 **11:00–14:30**（总窗内）；日软 1400 / 时软 420；**到软上限当日停，次日总窗续跑**。  
- 已有 `mode=backfill_mootdx_0925` 且 status 明确可跳过（`FORCE=1` 才重跑）。  
- 新取数平台：先调研配额再写入 `platform_rate_limits.json`，禁止未登记打量。  
- **trades 入录成功 → HTML + Pages 双端同步**（族铁律：`首板战法/规范/首板战法总规范.md` §1）。

### 2.2 单日预筛 / 终选

```bash
python3 stock_v2.py --stage d0-preselect --date 2026-01-06
python3 stock_v2.py --backfill --date 2026-01-06
```

预筛必须：共享涨停池 → Stage B 补换手 → 再换手带；**禁止**只调 `stock_zt_pool_em`。

### 2.3 早盘 live（非历史）

`scripts/stock_v2_0924_entry.sh` — 腾讯竞价快照，**不占 tdx 历史配额**。

## 3. 复核清单（每次回补批次）

开跑前：

- [ ] 已读《取数平台与限流规范》；`quota_status()` 无异常 stopped  
- [ ] `DISABLE_BAOSTOCK` 状态符合当日决策（默认 1）  
- [ ] 不与主板 `board_price` 抢同一平台高峰（夜班 vs 11–14:30 已错峰）

批次中：

- [ ] Stage A 历史日 `n>0`（允许 sparse）  
- [ ] 缺换手 → `REVIEW_REQUIRED` / MISSING，不是「D0涨停池为空」  
- [ ] 竞价：有 tick → VERIFIED；无 tick → AUCTION_MISSING 或 BACKFILL_OPEN，**无全天量填竞价量**

批次后：

- [ ] 统计：涨停池数 / 首板候选数 / 日线覆盖 / 竞价覆盖 / OK 推荐数  
- [ ] 集合划分：  
  - **集合 A**：日线+首板完整（可研究换手/连板）  
  - **集合 B**：另加真竞价完整（才可报「完整 V2 竞价回测」）  
- [ ] 抽样交叉核验（另源）≥ 若干日 × 若干代码  

小流量试跑：先 **2026-01 若干日** 人工过目，再拉全年。

## 5. 与错误做法对照

| 错误 | 正确 |
|------|------|
| 只用东财涨停池补全年 | 磁盘 + ths +（解禁后）日线重建 |

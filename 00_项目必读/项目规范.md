## 2. 根目录白名单（铁律）

根目录**只允许**：

- `README.md`
- `requirements.txt`
- `.gitignore` / `.env.example`（可为指向 `05_配置文件/` 的符号链接）
- 编号目录 `00_`～`09-`
- **首板战法权威唯一路径**：`/Users/admin/stock_quant_select/首板战法/`（工作区根下；**禁止**在 `stock-quant-select/` 或 `01_量化模型/` 再留副本/软链）。细则：该包 `规范文档/目录与文档规范.md`
- `.git` / `.github` / `.cursor` 等工具目录

**禁止**在根目录新增：

- 说明类 / 报告类 `.md`、`.html`（`首板战法/` 包内文档除外）
- 跑批结果 `.json`
- 个人笔记、行程、无关脚本
- 第二个平行「首板」目录（禁止再在 `01_量化模型/` 实体复制一份）

违规文件按上表归入对应编号目录。

## 3. 文件组织原则

1. **关联放一起**：战法代码、配置、权威结果 JSON 在同一战法目录。  
2. **说明进 04 / 必读进 00**：长文说明不进根目录。  
3. **新模式**：需求 md 与代码同放在 `09-新模式/{策略名}/`，禁止散落在 `09-` 根下。  
4. **目录名禁止空格**（已将 `08_测试 git` → `08_Git测试`）。  
5. **子项目根只暴露主运行程序（全仓铁律，2026-10-28）**：  
   - 任意策略 / 工具包目录（如 `每日交易记录/`、`stock/`、`最新一进二/`、`09-新模式/{策略}/`）根下**只保留主入口 `.py`**（及该包 README）。  
   - 支撑模块 → `lib/`（或同义目录）；可独立跑的作业 / CLI → `jobs/`；shell → `scripts/`；说明 → `文档/` 或既有说明目录。  
   - **禁止**把辅助 `.py`、规范 md、状态 json 直接堆在该包根目录。  
   - 范例：`首板战法/每日交易记录/`（主运行仅 `stock_UI.py`）。

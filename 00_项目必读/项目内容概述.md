# 项目内容概述

> 日期：2026-11-02  
> 这份是当前在跑的内容说明。更早的《项目设计与运行逻辑总览》写于 2026-09-21，目录和时刻已过时，以本文为准。  
> 细则仍以首板战法规范文档和代码为准。本文不写口令、令牌。

## 这是什么

一套跑在本机上的 A 股选股和复盘系统。交易日早盘选出票、推到微信，收盘补买卖价和盈亏，看板在本机和 GitHub Pages 上都能看。

生产代码在工作区根的 `首板战法/`。GitHub 仓库是 `shen9220/stock-quant-select`。会话记忆在外层 `workspace/`，不进这个仓库。

## 现在在用的选股

| 名称 | 程序 | 做什么 |
|------|------|--------|
| Stock-V1 默认原 | `stock` | 前一交易日涨停池评分，取全局前二。买入日次日 09:35、13:15 各卖一半 |
| 主板 / 创业板 | 同一份 `stock` 记录上的 `board_rank` | 按板块各留前二。候选不足就空占位，不另拉涨停池重算 |
| Stock-V1 水下 | `stock_updata` | 集合竞价水下（绿开）前二 |
| Stock-V2 一进二 | `stock_v2` | 竞价终选。路径 A 高开，路径 B 平开或低开，各最多两名 |
| Stock（低价） | `slow` | 低价一进二。通知已暂停，选股仍可落盘 |
| Up | `up` | 强度首板。通知已暂停 |
| 涨停回头低吸 | `09-新模式/涨停回头低吸` | 独立流水线，V1 / V2 两套，和首板通知分开 |

口径：涨停日是选股日，买入日是下一交易日。原来的卖出是买入日的下一交易日，早盘 09:35、午盘 13:15。涨停或跌停卖不出，就顺延到下一交易日的同一时点。

从买入日 2026-11-02 起，交易记录多了四列：D2早盘卖价、D2早盘利润、D2午盘卖价、D2午盘利润。这里的 D2 是再拿一天，当天按开盘重新买入，早午各卖一半，利润相对这个新买价。更早的日期先不补。

## 一天怎么走

只在 A 股交易日发正式通知。周末和法定休市不推。

| 时刻 | 内容 |
|------|------|
| 07:50 | slow / up 预跑 |
| 08:40 | V2 的 D0 预筛 |
| 08:50 | stock、slow、up 主跑，通知钉在 09:05 |
| 09:06、09:10 | 09:05 通知缺了就补发 |
| 09:23 | 水下，入口内等到 09:24:40 |
| 09:24、09:28 | V2 竞价终选和看门狗，目标约 09:27 送达 |
| 09:40 / 11:25 / 14:30 | 回头低吸 V1 |
| 09:42 / 11:27 / 14:32 | 回头低吸 V2 |
| 15:00 | 交易记录 UI 里的收盘补全：买卖价、盈亏、到期的 D2 四字段 |
| 15:05 | 收盘 cron 兜底。补完后导出并推送 Pages |
| 15:30–20:30 | 卖价或 D2 四字段还空，大约每 30 分钟再补一次 |

回补取数的时间窗是每天 10:00 到次日 00:00。0 点到 10 点安静，给早盘正式通知让路。15:00–15:25 也让路给收盘任务。

## 通知

权威是 `首板战法/规范文档/规范要求/PushPlus通知规范.md`。

会发的：

- 早盘，本人和好友：09:05 的 V1、09:25 的水下、约 09:27 的 V2。
- 尾盘，只发本人，而且必须 15:00 之后：V1 原当日涨跌幅、创业板当日涨跌幅、当周最后交易日再加 V1 原周结果。一条接一条，等上一条回执成功再发下一条。

不发的：slow、up、V2 尾盘、主板当日和周结果、创业板周结果。手动测试只发本人。

## 回补现在补到哪

主板和创业板的买卖价按月份倒序补：每个月先补完创业板，再补完主板，然后上一个月，回到 2026 年 1 月。空占位、买不进、卖出日还没到的，不占这一档。

到 2026-11-02 为止：10 月买卖价已经齐（空占位除外）。下一档卖价是 9 月创业板，买价缺口在 8 月主板。更早月份买价大多有，卖价还很少。

暂停的回补：主板/创业板夜班涨停池 `board_night`，V2 历史竞价回补。标志文件还在：`V2_HIST_PAUSED`、`BACKFILL_PAUSED`。

## 看板

本机：`首板战法/交易记录UI/stock_UI.py`，常驻 LaunchAgent `com.stockquant.stock-ui`。

Pages：https://shen9220.github.io/stock-quant-select/trade-ui/

交易落盘、15:00 收盘补全结束、或者本机 HTML 比 Pages 副本新，都会导出 `docs/trade-ui` 并 push。公开页是脱敏快照，登录后看加密全文。

# 涨停回头低吸选股交易系统 — 需求规格说明书（V1.0）

> 适用于 Cursor 自动开发：前端界面 + 每日定时数据拉取 + 人工编辑交互。

---

## 1. 总体目标

构建一套 A 股主板涨停回调低吸的交易辅助系统，包含：

- 每日自动扫描符合基础条件的股票，放入「涨停观察池」。
- 观察池内股票等待回调到 10 日与 20 日均线之间，并满足调整天数后，可自动或手动触发买入。
- 买入后进入「买入持有池」，按纪律持有，自动同步买入/卖出参考价，并记录盈亏。
- 所有记录可编辑、可删除、可筛选，便于复盘。

**核心原则**  
- 只做主板，股价 ≤ 30 元，非 ST。  
- 最近 10 个交易日首次涨停，视为趋势确立。  
- 涨停后回调到 10 日与 20 日线之间，视为低吸区间。  
- 调整 3-5 天后买入，最迟第 7 天卖出。  
- 严格止损：跌破 20 日线且亏损 5% 左右出局。  
- 每轮只持有一只股票，卖出后才能开始下一轮。

## 2. 术语与关键定义

| 术语 | 定义 |
|------|------|
| 主板票 | 沪深 A 股主板，代码以 `600` / `601` / `603` / `605` / `000` / `001` / `002` / `003` 开头；排除创业板（`300` / `301`）、科创板（`688` / `689`）、北交所（`8` / `4` 开头）。 |
| 上市满 5 年 | 从上市日期至当日的自然年数 ≥ 5 年。 |
| 市盈率 < 28 | 采用滚动市盈率（PE-TTM），且必须 > 0（排除亏损股）。 |
| 连续 2 年分红且分红率 ≥ 20% | 最近两个完整会计年度，每年现金分红总额 ÷ 当年归母净利润 ≥ 20%。 |
| 最近 10 天首次涨停 | 以交易日计算，回溯最近 10 个交易日（含昨日），昨日涨停，且此前 9 个交易日内未涨停。 |
| 涨停日 | 记为 T 日（第 0 天）。 |
| 涨停后一日 | 记为 T+1 日，即涨停后的下一个交易日。 |
| 调整天数 | 从 T+1 日算起，T+1 为调整第 1 天，T+2 为第 2 天，依次类推。 |
| 10/20/25/30 日线 | 简单移动平均线，取最近 N 个交易日收盘价（含当日）的平均值。 |
| 回调到 10 日和 20 日线之间 | 最新价满足：`20 日均线 < 最新价 < 10 日均线`，且均线呈多头排列（10 > 20）。若均线交叉则视为不满足。 |
| 涨停 | 昨日收盘价较前一日收盘价涨幅达到主板涨停标准（四舍五入，一般 +10%，非 ST），且收盘价等于涨停价。 |
| 买入日 | 首次建仓成交日，记为持仓第 1 个交易日。 |
| 卖出日 | 最后一次卖出成交日。 |
| 交易日 | 仅考虑 A 股实际交易日，排除周末及法定节假日。 |

## 3. 每日选股扫描条件

每天（交易日）盘后（建议 15:30 后）执行自动扫描，筛选出满足以下**全部条件**的股票：

1. 股票代码属于沪深主板（见术语定义）。  
2. 最新股价 ≤ 30 元。  
3. 非 ST、非 *ST。  
4. 上市满 5 年。  
5. PE-TTM > 0 且 < 28。  
6. 最近两个完整会计年度每年现金分红率 ≥ 20%。  
7. 最近 10 个交易日（含昨日）内，昨日首次涨停。  
8. 涨停日不是一字涨停（即涨停当日有非涨停价成交，否则无法买入，直接排除）。  
9. 昨日涨停后，当前股价或最近交易日股价位于 10 日与 20 日均线之间，或尚未进入但预期会回调进入（保留在观察池，每日更新均线后判断）。

满足条件的股票**自动加入观察池**，若已存在则跳过（去重）。

## 4. 系统实体与数据字段

### 4.1 涨停观察池（Observation Pool）

每一只进入观察池的股票生成一条记录，字段如下：

| 字段名 | 说明 | 是否自动更新 | 是否可编辑 |
|--------|------|--------------|------------|
| 股票代码 | A 股 6 位代码，唯一标识 | 自动带入 | 否（唯一键） |
| 股票名称 | 股票简称 | 自动带入 | 是 |
| 涨停日期 | 首次涨停日（T 日），格式 `YYYY-MM-DD` | 自动带入 | 是 |
| 所属行业板块 | 按数据源返回的行业分类，取主要行业 | 自动带入 | 是 |
| 所属概念板块 | 按数据源返回的概念标签，取占比最大或最相关的一个 | 自动带入 | 是 |
| 涨停后一日开票价格 | T+1 日开盘价 | 自动带入（T+1 盘后写入） | 是 |
| 10 日线股价 | 最近 10 个交易日收盘价均值 | 每日盘后自动更新 | 可编辑，但会被覆盖 |
| 20 日线股价 | 最近 20 个交易日收盘价均值 | 每日盘后自动更新 | 可编辑，但会被覆盖 |
| 25 日线股价 | 最近 25 个交易日收盘价均值 | 每日盘后自动更新 | 可编辑，但会被覆盖 |
| 30 日线股价 | 最近 30 个交易日收盘价均值 | 每日盘后自动更新 | 可编辑，但会被覆盖 |
| 最新价 | 最近收盘价 | 每日盘后自动更新 | 否 |
| 状态 | 观察中 / 已买入 / 已失效 | 自动更新 | 可手动修改 |
| 进入观察池日期 | 首次加入日期 | 自动 | 否 |
| 备注 | 可选 | — | 是 |

### 4.2 买入持有池（Position Pool）

买入后从观察池移入持有池（或复制并标记状态）。持有池字段在观察池基础上增加：

| 字段名 | 说明 | 是否自动更新 | 是否可编辑 |
|--------|------|--------------|------------|
| 买入日期 | 首次建仓成交日 | 自动填入当日 | 是 |
| 买入价 | 实际成交价（自动同步参考价，可改） | 自动触发后填入 | 是 |
| 卖出日期 | 卖出成交日 | 自动填入 | 是 |
| 卖出价 | 实际卖出价（自动同步参考价，可改） | 自动触发后填入 | 是 |
| 利润率 | `(卖出价 - 买入价) / 买入价 * 100%`，保留两位小数 | 自动计算 | 可手动覆盖 |
| 是否盈利 | 利润率 > 0 则显示“是”，否则“否” | 自动计算 | 可手动覆盖 |
| 持仓天数 | 买入日至卖出日的交易日数 | 自动计算 | 可编辑 |
| 状态 | 持仓中 / 已卖出 / 已止损 | 自动更新 | 可手动修改 |

> 持有池中同一只股票可能因补仓产生多次买入，但最终合并为一条记录，买入价更新为**加权平均成本价**。  
> 同时只允许存在一条“持仓中”记录。

### 5.1 整体布局

- 顶部：系统标题 + 全局操作区（执行扫描、手动刷新数据）
- 主 Tab 切换：
  - **涨停观察池**
  - **买入持有池**

- 表格区：展示对应字段，支持行内编辑、操作按钮。
- 底部：分页器（每页可配置 20 / 50 / 100 条）。

### 5.2 涨停观察池 Tab

**字段展示顺序**（按用户要求）：  
`涨停日期`、`股票名称`、`所属概念板块`、`所属行业板块`、`涨停后一日开票价格`、`10日线股价`、`20日线股价`、`25日线股价`、`30日线股价`、`状态`、`备注`、`操作`

（股票代码作为隐藏列或点击展开，保证不冗余但可查询）

**筛选器**：
- 日期筛选（涨停日期范围）
- 股票筛选（股票名称或代码模糊搜索）
- 行业板块筛选（下拉选择）
- 概念板块筛选（下拉选择）

**操作**：
- 新增：输入 `股票名称`、`日期`（涨停日期），点击确定后自动查询并补充其余字段。
- 删除：需二次确认。
- 编辑：所有可编辑字段可点击编辑（行内或弹窗），保存后更新。
- 手动标记失效：状态改为“已失效”。

### 5.3 买入持有池 Tab

**字段展示顺序**：  
`涨停日期`、`股票名称`、`所属概念板块`、`所属行业板块`、`涨停后一日开票价格`、`10日线股价`、`20日线股价`、`25日线股价`、`30日线股价`、`买入日期`、`买入价`、`卖出日期`、`卖出价`、`利润率`、`是否盈利`、`持仓天数`、`状态`、`备注`、`操作`

**筛选器**：  
同观察池，额外增加：
- 是否盈利（全部 / 盈利 / 亏损）
- 状态（持仓中 / 已卖出 / 已止损）

**操作**：
- 新增买入：弹窗输入 `股票名称`、`买入日期`、`买入价`，其他字段自动从观察池或行情数据补充。
- 编辑：所有可编辑字段可修改。
- 删除：二次确认。
- 手动卖出：输入卖出日期、卖出价，计算利润率。
- 查看/编辑补仓：若该记录有补仓，可编辑买入价为加权成本。

## 6. 买入 / 卖出自动同步规则

### 6.1 买入价自动同步

- 针对观察池中状态为“观察中”的股票，在 T+3 日（涨停后第 3 个交易日）开始监控。
- 触发条件（满足任一即可）：
  1. **时间触发**：T+3、T+4、T+5 交易日的 **14:30** 左右（允许 ±5 分钟），取当时最新价作为买入参考价。
  2. **跌幅触发**：在 T+3、T+4、T+5 任意一天，若当日实时跌幅（相对昨收）达到 **-3%**，立即取当前价作为买入参考价。
- 触发后自动执行：
  - 将股票从观察池移入持有池。
  - 自动填入 `买入日期` 和 `买入价`（参考价）。
  - 弹出提示，用户可修改实际成交价后确认。
- 若 T+5 收盘仍未触发，则该股票状态标记为“已失效”，不再自动买入，但可手动新增买入。
- **补仓规则**：若在 T+4 或 T+5 再次触发跌幅 -3%，可提示补仓；用户确认后，系统自动更新买入价为加权平均成本。不自动强制补仓。

### 6.2 卖出价自动同步

- 持仓天数从买入日算起，买入日为第 1 个交易日。
- **正常到期卖出**：持有第 7 个交易日 **14:00**（允许 ±5 分钟），取当时最新价作为卖出参考价，自动填入 `卖出价` 和 `卖出日期`，状态改为“已卖出”。
- **止损卖出**：当最新价跌破 20 日均线，且持有收益率 ≤ -5%（即现价 ≤ 买入价 * 0.95），触发止损。自动按当前价填入卖出价，状态改为“已止损”。
- **强势卖出**：持仓期间任一交易日，若出现以下任一情况：
  - 盘中触及涨停价（即使未封住） → 提示卖出并记录参考价。
  - 盘中最高涨幅 ≥ 7% 但未涨停 → 提示冲高回落卖出，记录当时价格。
  自动触发后填入卖出价和卖出日期，状态改为“已卖出”。
- 所有自动填写的卖出价均支持手动编辑。

## 9. 边界情况与遗漏补全

1. **一字涨停无法买入**：扫描时排除涨停当日为“一字板”的股票（开盘价 = 涨停价且全天无打开）。  
2. **停牌**：若股票停牌，跳过当日更新，状态可标记“停牌”。  
3. **均线交叉**：若 10 日线 ≤ 20 日线，则不满足“回调到两线之间”，自动移出观察池或标记失效。  
4. **同一天多只股票符合**：观察池可有多个，但买入时系统限制只能买一只，买入后其他观察池股票状态可保持“观察中”但不可再买入。  
5. **手动新增观察池时**：若股票代码查询不到或不符合主板条件，前端提示错误。  
6. **手动编辑均线**：如果用户手动修改均线，当日的自动更新会覆盖，因此建议自动更新前检测是否被手动锁定；若未锁定则更新。  
7. **买入价自动同步但无实际成交**：自动填入参考价后，用户必须手动确认实际成交价；若未确认，状态保持“待确认”，不进入持有池。  
8. **卖出价自动同步但实际未卖出**：自动填入后用户可修改，状态由用户确认。  
9. **补仓导致持仓天数计算**：持仓天数仍从首次建仓日算起，不因补仓重置。  
10. **已卖出记录再编辑**：支持修改买入/卖出价重新计算利润。  
11. **历史记录保留**：卖出后的记录不删除，状态改为“已卖出”，仍保留在持有池列表中供筛选。  
12. **概念板块占比**：若数据源无法提供“占比最大”，则取第一个概念标签或资金流入最大的概念。

## 10. 示例流程

1. 2026-09-07 盘后扫描，某股票符合条件，加入观察池，涨停日期 2026-09-04（T 日）。  
2. 2026-09-08 为 T+3 日，14:30 触发买入监控，最新价 15.20 元自动填入，用户确认。  
3. 该股票移入持有池，买入日期 2026-09-08，买入价 15.20。  
4. 持有期间每日更新均线，持有第 7 天 14:00 自动记录卖出价 16.10，利润率 +5.92%，状态已卖出。  
5. 用户可编辑卖出价，系统重新计算利润。

## 12. 验收要点

- 每日扫描结果准确，观察池去重正常。  
- 买入价 / 卖出价自动同步触发正确。  
- 持有池一次只能有一条“持仓中”记录。  
- 卖出后利润率计算正确。  
- 筛选器和编辑、删除功能正常。  
- 均线每日自动更新且不丢失关键记录。

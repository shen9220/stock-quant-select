# 股票量化选股模型系统

一套完整的股票量化选股策略系统，包含多个经过验证的交易模型。

## 快速开始

```bash
# 依赖
pip install -r requirements.txt
# 或
./02_智能工具/install_deps.sh

# 一键运行
cd 02_智能工具 && ./启动模型.sh
```

环境变量模板：`05_配置文件/.env.example`（根目录 `.env.example` 为符号链接）。
